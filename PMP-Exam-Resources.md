# PMP® Exam Blueprint: Situational Strategies, Agile Integrations & Case Notes 🎯

Welcome! This document breaks down the practical decision-making frameworks, core domains, and real-world scenario drills required to pass the **Project Management Professional (PMP)®** exam.

---

## 🧠 The "PMI Mindset" in 3 Golden Rules

When answering situational questions, ALWAYS run the scenario through these rules:

1. **Assess & Analyze First**: Never implement a solution or escalate to sponsors before evaluating the impact.
2. **Be a Servant Leader**: Coach the team, remove blockers, and resolve interpersonal conflicts through direct conversation.
3. **Respect the Governance**: Predictive projects require formal Change Requests (CR); Agile projects require Product Backlog refinement.

---

## 🔬 Practical Scenario Micro-Cases (Exam Drills)

### Case 1: The Team Conflict (People Domain)
> **Scenario**: Two senior developers are passionately arguing about the technical architecture of a new sprint feature. The debate is stalling current sprint progress. What should the Project Manager do FIRST?
>
> * **❌ Incorrect Action**: Decide the architecture for them to save time. *(Not servant leadership)*
> * **❌ Incorrect Action**: Escalate to the Functional Manager. *(Avoids conflict resolution)*
> * **✅ Correct PMI Action**: Facilitate a private meeting with both developers to help them evaluate trade-offs and reach a collaborative consensus.

### Case 2: Scope Creep in Agile (Process Domain)
> **Scenario**: A key stakeholder emails a developer directly, requesting an "urgent minor UI update" for the upcoming release. The developer starts working on it immediately. What should the Project Manager do?
>
> * **❌ Incorrect Action**: Formally submit a Change Request to the Change Control Board (CCB). *(Overkill for Agile)*
> * **✅ Correct PMI Action**: Advise the stakeholder that all new requests must go through the Product Owner to be prioritized in the Product Backlog.

## 📊 Essential Formulas & Metrics (Conceptual Focus)

You don't need heavy math for modern PMP exams, but you **must** understand what these indicators mean:

* **Schedule Performance Index ($SPI$)**: $\frac{EV}{PV}$
  * $SPI > 1.0$: Ahead of schedule 🟢
  * $SPI < 1.0$: Behind schedule 🔴
* **Cost Performance Index ($CPI$)**: $\frac{EV}{AC}$
  * $CPI > 1.0$: Under budget 🟢
  * $CPI < 1.0$: Over budget 🔴
